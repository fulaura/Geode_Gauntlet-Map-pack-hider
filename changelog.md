# Changelog

## v1.0.0
- Initial release of **Hide Completed Packs**!
- Added separate toggles to hide/show completed **Gauntlets** and **Map Packs**.
- Added in-game toggle buttons ("Hide Done") directly on the Gauntlets and Map Packs screens.
- Automatic page repacking for Gauntlets to eliminate blank screens and update page indicators cleanly.
- Automatic row filtering for Map Packs list views.
